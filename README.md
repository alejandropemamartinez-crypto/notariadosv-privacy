# Notariado SV — Política de Privacidad

Este repositorio público aloja únicamente la política de privacidad de **Notariado SV**.

La aplicación usa Google Mobile Ads (AdMob) para publicidad y Google User Messaging Platform (UMP) para mensajes de privacidad/consentimiento cuando corresponda.

El archivo que debe publicarse con GitHub Pages es `index.html`.

Paquete Android: `sv.notariado.app`
